# Registros de trabalho

Esta pasta guarda desenhos, planos e relatórios datados de entregas e análises anteriores. Cada arquivo descreve seu próprio escopo e o estado observado naquele momento.

Esses registros são históricos ou derivados: suas caixas marcadas, planos preparados e relatos de execução não provam o estado operacional atual nem o aceite completo de uma tarefa. Para regras, use o [GDD](../GDD.md); para escopo, o [MVP](../MVP.md); para decisões, os [ADRs](../ADRs/); para estado operacional, consulte o Trello e a evidência vinculada.

## Pastas

- `specs/` — desenhos específicos de entregas.
- `plans/` — planos de implementação correspondentes.
- `reports/` — relatos de validação e revisão; evidência registrada permanece limitada ao escopo descrito no próprio relatório.
- `notas/` — descrições datadas da implementação observada; não são contratos normativos.
